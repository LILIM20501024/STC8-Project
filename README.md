# STC8A8K64S4A12 单片机综合实验项目

本项目基于艾克姆 IK-STC8 开发板（主控：STC8A8K64S4A12），使用 C 语言编写，实现了 LCD 显示、按键控制、流水灯、蜂鸣器及内部定时器时钟等综合功能。

## 🌟 实现功能
1. **LCD12864 显示**：屏幕静态显示学号与姓名。
2. **按键控制流水灯**：按下 KEY1，流水灯（D1-D4）暂停/继续交替闪烁。
3. **按键控制蜂鸣器**：按下 KEY2，蜂鸣器长鸣/关闭（含开机滴声自检）。
4. **实时时钟**：利用定时器 0 实现秒级走时，并动态显示在屏幕第三行。

## 🔌 硬件引脚分配 (核心避坑指南)

经过反复测试，本板子的引脚复用和冲突较多，以下为**实测可用**的引脚分配：

### 1. LCD12864 屏幕
| 屏幕引脚 | 单片机引脚 | 备注 |
| :--- | :--- | :--- |
| RS (指令/数据) | **P3.5** | 需配置为准双向输出 |
| RW (读/写) | **P3.4** | 需配置为准双向输出 |
| E (使能) | **P3.2** | 需配置为准双向输出 |
| Data (D0-D7) | **P6** | 需配置为准双向输出 |

### 2. 独立按键
| 按键 | 单片机引脚 | 功能 |
| :--- | :--- | :--- |
| KEY1 | **P3.7** | 控制流水灯启停 (需设为高阻输入) |
| KEY2 | **P3.6** | 控制蜂鸣器开关 (需设为高阻输入) |

### 3. 流水灯与蜂鸣器
| 外设 | 单片机引脚 | 备注 |
| :--- | :--- | :--- |
| 流水灯 D1 | **P2.6** | 低电平点亮 |
| 流水灯 D2 | **P2.7** | 低电平点亮 |
| 流水灯 D3 | **P7.2** | 低电平点亮 |
| 流水灯 D4 | **P7.1** | 低电平点亮 |
| 蜂鸣器 (控制) | **P2.0** | **必须配置为强推挽输出**，低电平触发 |
| 蜂鸣器 (电源/继电器) | **P1.5** | **必须配置为强推挽输出**，低电平供电 |

## 🛠️ 开发环境
* **IDE**: Keil uVision4 / uVision5 (C51)
* **下载软件**: STC-ISP
* **晶振频率**: 11.0592 MHz

## ⚠️ 关键代码说明 (防踩坑)
1. **端口模式配置**：STC8 系列单片机 I/O 口上电默认是高阻输入，无法直接驱动外设。代码中针对屏幕、按键、蜂鸣器分别配置了准双向、高阻输入和强推挽输出模式。
2. **按键消抖与防卡死**：代码使用了“边沿检测法”（检测上一次和当前的按键状态），彻底避免了传统 `while(KEY==0);` 导致按一下整个系统卡死的问题。
3. **定时器中断**：Timer0 配置为 1ms 中断，用于精准计算时间，不影响主循环的流水灯和按键扫描。
